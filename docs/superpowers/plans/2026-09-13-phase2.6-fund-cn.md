**Goal:** 场外中国基金（6 位代码，如 110022）作为新资产类型接入行情/持仓/快照/曲线全链路（天天基金免费净值源）；持仓页增加类型筛选 Tab（全部/股票/ETF/基金/黄金/其他）。

**Architecture:** 后端 `pkg/quote/fundcn.go` 新增 FundCNProvider（实时估值 jsonp + 历史净值 f10 接口，均无 key）挂入降级链第三位；asset type 白名单加 `fund`、price_source 加 `fund_cn`（创建时强制 CNY+fund+6 位码校验，同 gold 的强制模式）；YahooProvider 对纯 6 位数字 symbol 快速 ErrUnsupported（避免无效上游调用）。前端 AssetDialog 第五预设「中国基金」、InvestPage 类型筛选 Tab（筛选只影响持仓表，汇总卡恒为全部——防止误读总资产）。

**Tech Stack:** 同前（Go/Gin/sqlx/Redis；React 19/TS strict/TanStack/shadcn）。

**Spec:** `docs/superpowers/specs/2026-09-12-personal-site-redesign-design.md` §4（本计划落地时需同步修订 §1 投资行/§4.1 数据源/type 枚举——Task 2.6.3 文档步骤执行）

## Global Constraints

- 降级链语义不变：FundCN 失败 → last-known 兜底（Stale），Quotes/PEs 永不 error，positions 恒 200
- fund_cn 资产：symbol=纯 6 位数字（创建时校验 + 强制 type=fund、currency=CNY，忽略入参，同 computed_gold_cny 强制模式）；PE 恒 null（fund_cn 不进 PEs 请求列表——基金无 PE 语义）
- 基金净值语义：盘中 gsz>0 用估值（PreviousClose=dwjz）；否则用 dwjz 官方净值（PreviousClose=0 → 前端日涨跌 "—"）；净值日频更新与 60s 缓存/每日快照兼容
- 天天基金接口（2026-09-13 实测修订，Ruling：原 fundgz jsonp 源已被 CDN 判死返回静态 404 页，弃用）：实时 `https://fundmobapi.eastmoney.com/FundMNewApi/FundMNFInfo?...&Fcodes={code}`（JSON，Datas[0] 含 NAV/PDATE/GSZ/GSZZL/GZTIME/SHORTNAME；GSZ>0 用估值且 PreviousClose=NAV，否则用 NAV 且 PreviousClose=0；NAV 缺失/"--" → error）；历史 `https://api.fund.eastmoney.com/f10/lsjz?fundCode={code}&pageIndex={n}&pageSize=20` **必须带 Referer `http://fundf10.eastmoney.com/` 与 UA**，**单页硬上限 20 行**——pageIndex 递增翻页至累计 ≥ days 或空/短页，页数上限 20；响应 Data.LSJZList[{FSRQ:"2006-01-02",DWJZ:"3.4560"}]（DWJZ "--"/空跳过，逆序转升序）
- 快照范围扩为 price_source IN ('yahoo','computed_gold_cny','fund_cn')
- 筛选 Tab 只影响持仓表行；汇总卡/曲线/占比/流水不受筛选影响（全局口径）
- 单测：fundcn jsonp/lsjz 解析 + 双 guard（6 位判定）httptest 覆盖；go build/vet/test 全绿无回归（现有 48+）
- 惯例全沿用：Go 本地日期/IFNULL/PID 精确 kill/显式 git add/8080 勿动（PORT=8090 验证）/smoketest/conventional commits

type FundCNProvider struct { client *http.Client; fundMNFInfoBaseURL, lsjzBaseURL string }
func NewFundCNProvider(client *http.Client) *FundCNProvider
