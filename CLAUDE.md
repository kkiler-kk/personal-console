# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

A personal blog system with a React frontend and Go backend. Uses MySQL for persistence and Redis for caching.

- **Frontend**: React 19 + Vite + TypeScript (SPA on `localhost:3000`)
- **Backend**: Go 1.22 + Gin (REST API on `localhost:8080`)
- **Database**: MySQL 8.0 (via docker-compose)
- **Cache**: Redis 7 (via docker-compose)
- **ORM**: sqlx (not GORM)
- **Auth**: None — single-user passthrough (`SingleUserMiddleware` injects `users.id=1` on every request). JWT login/register removed 2026-09-13 by explicit user decision; `pkg/jwt.go` kept dormant as the restoration base. **Must be restored before any public / untrusted-LAN deployment** (see Key Design Decisions + BACKLOG.md top item)

## Architecture

### Backend (`backend/`)

Entry point: `cmd/main.go` → loads config, init DB + Redis, auto-migrates tables, starts router.

- `config/` — Config loading (environment variables; `backend/.env` is NOT auto-loaded — export vars or rely on defaults), MySQL (`sqlx`), Redis connections; `QuoteProxy` for quote upstream
- `handler/` — HTTP handlers: `user.go` (profile only — login removed 2026-09-13), `post.go` (CRUD + archive), `category.go` (CRUD), `comment.go`, `dashboard.go` (summary incl. portfolio + learn fields `study_minutes_today`/`learn_streak`/`review_due` + habit fields `habits_checked_today`/`habits_total`), `upload.go`/`gallery.go`, `asset.go` (asset CRUD + manual price + `Reorder` for persisted drag-sort; `type`/`price_source` whitelists via binding `oneof`, and `price_source=fund_cn` requires a bare 6-digit symbol while force-setting `type=fund`/`currency=CNY`), `trade.go` (trade CRUD + oversell guard), `invest.go` (positions/quotes/price-history/value-curve + `RefreshQuotes` — POST `/invest/refresh` force-refreshes quotes and PEs bypassing Redis caches, reusing the shared `peSymbols` filter and `service.AutoTrackedWhere` predicate, returns four counts and never 500s on upstream failures), `learn.go` (language profiles list/upsert, study session list [GET `/learn/sessions`, limit default 100 clamped 1–200, returns `sessions` + full `total`]/create/delete, stats, yearly calendar), `habit.go` (habit CRUD, check/uncheck idempotent via composite PK, yearly heatmap; `TodayCounts` reused by dashboard), `search.go` (⌘K site-wide search — five-category aggregation over posts [published only]/assets/habits [unarchived]/categories/tags; `q` required, 1–50 runes else 400; LIKE wildcards `%`/`_`/`\` escaped; each category fails independently to `[]`, response always carries all five keys)
- `middleware/auth.go` — `SingleUserMiddleware`: single-user passthrough (sets `userID=1`/`username=felix` on every request, no token check). The full JWT implementation lives in this file's git history — restore it (with `pkg/jwt.go`) before any non-local deployment
- `model/model.go` — Data models (User, Post, Category, Tag, PostTag, Asset [incl. `SortOrder`], Trade, PriceHistory, LanguageProfile, StudySession, Habit, HabitLog; `Habit.CheckedToday` is a query artifact filled only by the List subquery)
- `pkg/jwt.go` — JWT token generation/validation utilities (dormant since the 2026-09-13 auth removal; kept as the base for restoring auth)
- `pkg/portfolio/` — Pure functions: weighted-average position P&L (`positions.go`), portfolio value curve (`history.go`); unit-tested
- `pkg/learn/` — Pure function: study streak computation (`ComputeStreak`, local-timezone day keys); unit-tested
- `pkg/quote/` — Quote subsystem: Yahoo → Stooq → FundCN → last-known fallback chain, 60s Redis cache, gold-gram conversion (`GOLD_CNY_G`), USDCNY FX; providers unit-tested via httptest. `FundCNProvider` (`fundcn.go`) serves China OTC mutual funds (Eastmoney/Tiantian: `FundMNFInfo` for latest NAV/intraday estimate, `f10/lsjz` for history — Referer required, 20 rows/page hard cap so it paginates) and is the chain's last provider; `IsFundCNSymbol` (`^\d{6}$`) is the single routing guard: FundCN rejects everything else, and Yahoo's `Fetch`/`History` reject bare 6-digit codes *before* dialling out (A-shares like `600519.SS` carry exchange suffixes and stay on Yahoo) — zero wasted upstream requests. A single `quote.Service` instance is constructed in `main.go` and passed into `router.Setup`, shared by asset/invest handlers and the snapshot scheduler. `QuotesForce`/`PEsForce` are the force variants backing the refresh endpoint: they skip cache **reads** only — successful results are still cached (`cacheQuote`/`cacheFundamental`, incl. PE null anti-penetration writes) and still `writeBackPrice`, and failures still degrade to stale/null, so the "quotes never break the page" contract is unchanged. Note: force does not propagate through `goldResolver` (its internal `Quotes(GC=F, CNY=X)` and the summary `USDCNY` stay on their caches — BACKLOG item)
- `service/snapshot.go` — robfig/cron daily price snapshot (06:00 Asia/Shanghai) for auto-tracked assets, with startup catch-up (the 1-year history backfill lives in `handler/asset.go`, triggered async on auto-tracked asset creation). The auto-tracked SQL predicate is exported as `service.AutoTrackedWhere` (`price_source IN ('yahoo','computed_gold_cny','fund_cn')`), shared by snapshot and the refresh endpoint — single source, do not duplicate
- `router/router.go` — Gin route setup with public and protected groups (the "protected" group now just runs `SingleUserMiddleware` — the split is historical, there is no real auth)
- `cmd/migrate.go` — Auto table creation on startup

### Database Schema

Tables: `users`, `categories`, `posts`, `tags`, `post_tags` (many-to-many), plus invest-module tables `assets` (carries `sort_order` INT NOT NULL DEFAULT 0 — persisted custom display order; List/positions `ORDER BY sort_order`, `PUT /api/assets/reorder` rewrites 1..N; legacy rows normalized to `sort_order=id` by migrate), `trades`, `price_history` (unique `symbol`+`date`), plus learn-module tables `language_profiles` (unique `lang`, upsert) and `study_sessions` (multiple rows per day, `session_date` DATE indexed), plus life-module tables `habits` (nullable `icon`/`color`, `archived` soft-hide) and `habit_logs` (composite PK `habit_id`+`log_date` — one row per habit per day, INSERT IGNORE makes check-in idempotent). Posts have `slug`, `status` (published/draft), `view_count`. See README.md for full schema.

### Key Design Decisions

- **无认证是用户明确决定（2026-09-13）** — Single-user local deployment: `SingleUserMiddleware` passes every request through as `users.id=1`; login/register endpoints and the frontend Login flow are removed. This is **not** an oversight — but the backend listens on all interfaces with no auth, so anyone on the LAN can read/write everything incl. financial data. **Restoring auth before any public/untrusted-network deployment is a hard precondition**: rebuild from `pkg/jwt.go` (kept dormant) + the JWT middleware in `middleware/auth.go`'s git history; the seeded `felix` user (id=1, `cmd/migrate.go`, idempotent INSERT IGNORE) carries a non-loginable placeholder bcrypt hash — change that password first when auth returns. Adjudication checklist: spec §8 + BACKLOG.md top item.
- **持仓自定义顺序 sort_order 持久化** — `assets.sort_order` is the single source of display order (List/positions `ORDER BY sort_order, created_at`); `PUT /api/assets/reorder` demands the exact full id set (missing/extra/duplicate → 400) and rewrites 1..N inside one transaction. Frontend: HTML5 native DnD (no library) on the positions table, enabled only in filter=all + no column sort; optimistic `setQueryData` then mutate, invalidate-refetch on success, refetch-rollback + toast on failure.
- **sqlx over GORM** — Lightweight, explicit SQL. No GORM magic.
- **Redis caching** — Post lists, categories, tags cached 5–30 min. Cache invalidated on post/category/tag mutations. Quote responses cached 60s; USDCNY FX cached 1h.
- **First user is admin** — No role column; the first user in the database gets admin privileges implicitly (registration and login are both retired; the `felix` user id=1 is seeded idempotently by `cmd/migrate.go`).
- **Slug-based URLs** — Posts and categories use human-readable slugs, not IDs.
- **品牌字符串契约（Felix 改名）** — The brand name「Felix 控制台」now appears in exactly **two** places: `frontend/index.html` `<title>` and `Sidebar.tsx` header (the third place, `Login.tsx` CardTitle, was removed with the login flow on 2026-09-13). Besides the brand, one more `Felix` literal exists — the `AdminProfile` nickname input placeholder「如 Felix」(example copy, flagged as the fourth Felix string by the previous iteration's final review when Login.tsx still existed). Renaming the site means editing these strings **plus** the data row `users.nickname` (greeting/Topbar avatar menu derive from `AuthContext` user state at runtime, never hardcoded; the migrate seed also writes nickname `Felix`). Do not scatter the brand name elsewhere.
- **Positions are not stored** — No positions table; holdings are derived from `trades` at request time via pure functions in `pkg/portfolio` (weighted-average cost). `trades` is the single source of truth; trade prices are historical facts, independent of live quotes.
- **Quote fallback chain** — Yahoo (v8 chart) → Stooq (CSV) → FundCN (Eastmoney NAV; bare 6-digit China fund codes only) → last-known price from `assets.current_price` (marked `stale`). The UI must never break because quotes fail. Upstream HTTP goes through `QUOTE_PROXY`. Gold accumulation (`GOLD_CNY_G`) is computed as `GC=F ÷ 31.1035 × USDCNY`. Fundamentals: Yahoo v7 quote (cookie+crumb), PE(TTM) cached in Redis for 1h; any failure yields `pe_ttm: null` and never blocks positions.
- **基金净值日频（fund_cn）** — Fund NAV is daily, not minute-level: intraday the estimate `GSZ` is used as price with the official NAV `NAV` as `previous_close` (so the daily change is meaningful); after close / on non-trading days `GSZ` is null → price is `NAV`. The upstream-echoed `FCODE` **must** equal the requested symbol or the quote is rejected outright — a mixed-up NAV silently written into `current_price` / the daily snapshot / the backfilled history is undetectable data corruption in a bookkeeping system, so degrade to last-known instead. Numeric fields accept string / number / null and the `--` placeholder, and NaN/Inf are explicitly rejected (NaN slips past every `<= 0` guard, then panics gin's JSON render → 500, breaking the "quotes/positions never error" contract). History comes from `f10/lsjz`, which requires a `Referer` header (403 without it) and caps pages at 20 rows, so it paginates up to 20 pages and reverses to ascending order. `fund_cn` assets never request PE (funds have no P/E). The jsonp estimate source `fundgz.1234567.com.cn/js/{code}.js` found in older write-ups is **dead** (CDN serves a "page not found" HTML page) — do not resurrect it.
- **Daily snapshot** — robfig/cron at 06:00 Asia/Shanghai snapshots auto-tracked asset prices (`price_source IN ('yahoo','computed_gold_cny','fund_cn')`; manual assets excluded) into `price_history`, with startup catch-up (missed runs execute on boot). The portfolio value curve is derived from these closes + trades, not stored separately. Creating an auto-tracked asset triggers an async 1-year `BackfillHistory` for that symbol.
- **学习记录 = `study_sessions` 多条/日，打卡为派生概念** — No separate check-in table/column: "studied today" means at least one `study_sessions` row exists for that date; a `minutes: 0` row is a pure check-in. Streak/today/week/calendar are all derived from `study_sessions` at request time. Session create/delete DELs the `dashboard:summary` Redis cache (profile upsert doesn't — it affects no summary field).
- **随手记复用 posts + notes 分类** — Quick notes are plain `posts` rows under the seeded category `slug=notes` (`section=life`, seeded idempotently via `INSERT IGNORE` in `cmd/migrate.go`); no notes table, no notes API. The NoteSection queries `GET /api/posts?category=notes` under a dedicated `["notes"]` query key and degrades gracefully (input disabled + hint) if the seed category was deleted.
- **习惯打卡状态服务端驱动（checked_today）** — `GET /api/habits` rows carry `checked_today`, computed by a correlated subquery with the Go-local today string (never `CURDATE()`); the frontend never derives check state locally. Dashboard's habit card reuses `HabitHandler.TodayCounts` (checked/total, both filtered by `archived = FALSE` so archived habits' historical logs don't count). All habit mutations DEL the `dashboard:summary` Redis cache.
- **日期口径统一 Go 本地日期传参（禁 CURDATE()）** — Every "today / this week / last 28 days" SQL boundary is computed in Go (`time.Now()` formatted `2006-01-02`, local timezone) and passed as a query parameter; never MySQL `CURDATE()`/`INTERVAL` (the MySQL container runs UTC while the app runs +08:00 — phase 2 I-3 lesson). DSN keeps `loc=Local` so DATE columns scan as local midnight, same frame as `time.Now()`.
- **Playwright smoke test** — `frontend/scripts/smoke.mjs` runs an 11-step chain with a real browser, **no credentials needed** (no-auth since 2026-09-13): direct Dashboard (asserts NO /login redirect) → blog → admin posts → admin overview → site-wide search shape check (`GET /api/search?q=smoke` → 200, five keys always arrays) → life → comment create/delete → invest chain (create asset → set price → record trade → verify derived position via API → assert /invest page renders it → clean up) → learn chain (create study session dated today (local-date construction, not UTC ISO) → assert stats via API (`today.en` true, `minutes >= 25`, `streak >= 1` — `>=` tolerates the user's real same-day records) → assert /learn page renders → delete only the smoke-created session) → habit chain (create habit → check with explicit `date=today` → assert heatmap contains today with `count >= 1` → assert /life page renders via `h1:has-text("生活")` (never `text=生活` — the sidebar matches too, phase-1 lesson) → finally: uncheck + delete habit) → i18n default-language check (fresh context, no pinned language → English sidebar `text=Invest` + English year-month archive title `h1:text-is("YYYY-MM")` on `/blog?year=&month=`, derived purely from URL params) (`node frontend/scripts/smoke.mjs`, optional `BASE_URL` override, expects `STEP5 SEARCH PASS` + `STEP8 INVEST PASS` + `STEP9 LEARN PASS` + `STEP10 HABIT PASS` + `STEP11 I18N PASS` + `SMOKE PASS ✅`). Steps 1–10 run with `ui-lang=zh` pinned via `context.addInitScript` (written before any page script), so the legacy Chinese selectors are i18n-proof; step 11 runs in a separate unpinned context whose page also wires a `pageerror` listener into the final error check. Backend fixes are verified by targeted curl/API checks plus a full smoke re-run. Go unit tests cover `pkg/portfolio`, `pkg/quote` and `pkg/learn` pure logic; no frontend unit test suite yet.

- **三语 i18n，默认英文（2026-09-13 用户决定，迭代四）** — react-i18next zh/en/es; language lives in localStorage `ui-lang`, default & fallback `en`; switching is instant (no reload) and syncs cross-tab (storage event → `i18n.changeLanguage`, `useUiLanguage` hook — same convention as mask/displayCurrency). The three locale files must carry identical key sets: after adding any copy run `node frontend/scripts/check-i18n.mjs` (tsc does NOT catch missing translations). Switcher labels are endonyms (中文/English/Español) by design. Non-component modules (`lib/api.ts`, `AuthContext`, `errorText`) resolve strings via the `i18n.t()` singleton — never hooks.
- **后端错误消息保持中文，持久化内容语言中性** — backend error strings (`data.error`) are passed through untranslated; only the local fallback shells (network failure / non-JSON body / status shell) go through `errors.*` keys. Error-code-based backend i18n is BACKLOG #34. Content persisted to the DB must stay language-neutral — e.g. PostEditor inserts a fixed `![image]` Markdown alt (never a localized string), and dates stay `yyyy-MM-dd`.
- **smoke 钉 zh + step 11 断言默认英文** — `smoke.mjs` steps 1–10 pin `ui-lang=zh` via `context.addInitScript` so the legacy Chinese selectors (`h1:has-text("生活")`, `text=文章管理`, `input[placeholder="昵称"]`, `text=英语` …) need zero churn; step 11 opens a fresh unpinned context and asserts the default-English sidebar (`text=Invest`) plus the en year-month archive title (`h1:text-is("YYYY-MM")` — zh fallback would render「2026 年 9 月」and fail). **When changing any zh locale value, cross-check smoke.mjs's selector list first** — exact-string selectors depend on them.
